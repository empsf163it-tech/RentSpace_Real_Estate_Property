RENTSPACE STATIC WEBSITE
Pages: Home, Search, Property Details, Compare, List Property, About, Contact.
Owner/Agent Dashboard intentionally excluded.
Typography: font-family: 'Lexend Giga', sans-serif; loaded through Google Fonts.
Images: 0 JPEG property images bundled locally. Any remaining image uses its Unsplash image URL. Listing photo upload accepts JPG, PNG and WebP.
Features: responsive pages, search filters, sorting, compare up to three properties using browser localStorage, demo forms.
Important: This is a front-end prototype. Listings and prices are illustrative, not real or verified. Forms only show demo confirmation; they do not send or store data on a server. No login, database, moderation, verification service or secure image storage is implemented. Add a secure backend before launch. Google Fonts and remote fallback images require internet.
Open index.html in a browser or upload the folder to static hosting.
